# Game of Life

A Python implementation of Conway's Game of Life. The game simulates the evolution of a grid of cells based on simple rules.

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/Antoine-92/game-of-life-Antoine_Richard-CDOF2
   cd game-of-life
   ```
2. Run the project 
    ```bash
   python main.py
   ```
